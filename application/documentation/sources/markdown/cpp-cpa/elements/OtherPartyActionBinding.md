# Other Party Action Binding

## Description
The `OtherPartyActionBinding` element is used to define the binding of actions for the other party in a collaboration protocol agreement.

## Attributes
- `actionId`: The unique identifier for the action.
- `description`: A brief description of the action.
- `role`: The role associated with the action.

## Example
```xml
<OtherPartyActionBinding actionId="67890" description="Receive Order" role="Receiver" />
