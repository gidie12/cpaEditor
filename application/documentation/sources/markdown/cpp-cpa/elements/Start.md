# Start

## Type
- `dateTime`

## Format
- Written as `YYYY-MM-DDTHH:MM:SSZ`, for example `2026-10-09T10:44:32Z`.
- The `Z` means Zulu time (UTC). A date with an offset such as `2026-10-09T12:44:32+02:00` is the same moment and is also valid.

## In the CPA Editor
- The **Start date** field on the **General** tab.
- Below the field the same moment is shown in Zulu time and in the timezone set on the computer, for example `Zulu: 2026-10-09T10:44:32Z    Local: 2026-10-09 12:44:32 CEST (UTC+02:00)`.
- The button **Set to now** fills in the current date and time in Zulu time.
