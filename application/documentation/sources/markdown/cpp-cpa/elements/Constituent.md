# Constituent

## Attributes
- `idref`: The ID reference.
- `excludedFromSignature`: Whether excluded from signature (boolean, default: "false").
- `minOccurs`: The minimum occurrences (nonNegativeInteger).
- `maxOccurs`: The maximum occurrences (nonNegativeInteger).
