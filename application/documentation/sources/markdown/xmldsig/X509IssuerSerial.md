# X509IssuerSerial

## Attributes


## Sub-elements

- **[X509IssuerName](X509IssuerName.md)**: The name of the issuer.
- **[X509SerialNumber](X509SerialNumber.md)**: The serial number of the certificate.

## Examples

```xml
<ds:X509IssuerSerial xmlns:ds="http://www.w3.org/2000/09/xmldsig#">
  <ds:X509IssuerName>CN=Intermediate Certificate 1</ds:X509IssuerName>
  <ds:X509SerialNumber>150391976489862988175029128674197088349881622307</ds:X509SerialNumber>
</ds:X509IssuerSerial>

```
