PartyInfo

Attributes

  • partyName: The name of the party.
  • defaultMshChannelId: The default MSH channel ID.
  • defaultMshPackageId: The default MSH package ID.

Sub-elements

  • PartyId (unbounded)
  • PartyRef (unbounded)
  • CollaborationRole (unbounded)
  • Certificate (optional, unbounded)
  • SecurityDetails (optional, unbounded)
  • DeliveryChannel (unbounded)
  • Transport (unbounded)
  • DocExchange (unbounded)
  • OverrideMshActionBinding (optional, unbounded)
