MessagingCharacteristics

Attributes

  • syncReplyMode: The synchronous reply mode (default: "none").
  • ackRequested: Whether acknowledgment is requested (perMessageCharacteristics.type, default: "perMessage").
  • ackSignatureRequested: Whether acknowledgment signature is requested (perMessageCharacteristics.type, default: "perMessage").
  • duplicateElimination: Whether duplicate elimination is enabled (perMessageCharacteristics.type, default: "perMessage").
  • actor: The actor type (actor.type).
